# creed-backstage — handoff

**Purpose** Backstage developer portal: Software Catalog from `catalog-info.yaml`, API docs in Swagger
UI, multi-file OpenAPI bundled by Redocly CLI into a committed `catalog/<service>/dist/openapi.yaml`
read with `$text`. Node module,
not in the Maven reactor. User-facing docs: `README.md`.

## Run

```bash
cd creed-backstage && corepack yarn install && corepack yarn start   # :3003 frontend, :7007 backend
```

Sign in with "Enter" (guest). The catalog appears about a minute after backend start (first
processing pass). Catalog API from a shell needs a token:
`curl -s localhost:7007/api/auth/guest/refresh` → `backstageIdentity.token`.

## Landmines

- **A fragment is a whole document, so `paths:` cannot `$ref` it directly** — a path item must be
  `$ref`'d by JSON pointer into the fragment's `paths`. Generate the list (`openapi:combine`); by
  hand, every `/` in the path must be `~1`. Re-run it whenever a fragment adds or removes a path —
  `--check` catches a stale `openapi.yaml`.
- **`$text` does not resolve `$ref`** — hence the committed Redocly bundle; never point `$text` at
  `openapi.yaml` itself. (The `$openapi` placeholder module was the old way, removed 2026-10-07.)
- **Placeholders with relative paths do not work on `type: file` locations** — not even `$text`. The base is a bare path, so `new URL()` throws ("could not form a URL"), and there is
  no file URL reader. Development and the image both register a **URL** location served by
  `packages/backend/src/catalogFiles.ts` (`/api/catalog-files`, only when
  `creed.catalogFiles.directory` is set) and allow-listed in `backend.reading.allow`.
- **In-memory SQLite + `yarn start` failed**: `IPC request 'DevDataStore.load' timed out` for every
  plugin. The dev data store lives in the `backstage-cli` parent over IPC (5 s timeout), and that
  process is also running webpack. Fixed with file-backed SQLite (`backend.database.connection.directory:
  ../../.sqlite`).
- **`yarn install` failed on a fresh scaffold**: a published `@yarnpkg/*` package declares
  `got` via `patch:…#~/.yarn/patches/got-npm-11.8.2-c1eb105458.patch`, a file that only exists in
  yarnpkg/berry. The file is committed under `.yarn/patches/`, copied verbatim from berry. A
  `resolutions` override of the patch descriptor did **not** work.
- **The scaffolder needs `yarn` on PATH** and the machine has none; `corepack yarn` works for every
  command after scaffolding. Don't `corepack enable` (changes the global Node install) unless the
  user asks.
- Port **3003** for the frontend (Grafana is 3000); `app.baseUrl` and `backend.cors.origin` must
  match.
- **`{ key: a, b }` in YAML is two keys.** An unquoted `, ` inside a flow mapping ends the value; the
  rest becomes a key. Parses fine, bundles fine — only `openapi:lint` (`struct`) catches it. Quote.
- **`OpenApiDefinitionWidgetProps` types only three props**, but the widget spreads the rest onto
  `<SwaggerUI>`; Swagger options such as `filter` need the cast in `apiDocsModule.tsx`.
- Config arrays **replace**, not merge: an overlay's `catalog.locations` replaces the
  local one, which is the point.
